# Prerequisites
The following github repositories are needed externally:
```{bash}
https://github.com/kompetenzairbag/seablock dev2.1
https://github.com/kompetenzairbag/landfillpainting dev2.1
```
Any mod not listed shall be taken from the official mod portal.

Regular `git pull` is recommended on all repositories. Use symlinks `<repo-mod-path> -> <factorio-mods-folder>` to [bypass zipping](https://lua-api.factorio.com/latest/auxiliary/mod-structure.html#mod-folder-and-file-structure).

NOTE: When switching from 2.0 it is recommended to delete the SpaceMod_xxx mod and replace it with SpaceModFeorasFork (mod portal).
